Wintermute

Paste a client token to connect. Create one on the server with sudo scripts/clients.sh add name browser. The bare wintermuted -add-client flag is only for a server you start by hand, and needs WINTERMUTE_DB set to the same file that server opens — otherwise it writes the client to a database nothing reads and the token here is rejected.
